插件安装指引（读屏友好版）

面向使用 NVDA、争渡等读屏软件的用户，全程只需键盘。 安装一次即可长期使用；更新插件时按第五节操作。预计用时 10 分钟，建议先读完第一节再动手。

一、安装前准备 · 二、打开扩展管理页 · 三、开发人员模式并加载 · 四、验证安装 · 五、更新插件 · 六、卸载 · 常见问题

一、安装前准备

你需要两样东西：

  1. Edge 或 Chrome 浏览器（Windows 自带 Edge，推荐用 Edge）
  2. 插件文件包：首页下载的压缩包（zip），解压后里面有一个名为 extension 的文件夹——安装时选的就是它

解压方法：在文件资源管理器里找到压缩包，按菜单键（或 Shift+F10）， 选择「全部解压缩」，回车确认。记住解压后的位置，比如「桌面的 公式助手 文件夹」。

提示：如果开发者通过远程协助帮你安装，你只需要接通话控， 下面步骤由对方操作，你可以跟着听一遍熟悉流程。

二、打开扩展管理页（Edge）

  1. 打开 Edge 浏览器
  2. 按 Ctrl+L，焦点到地址栏
  3. 输入 edge://extensions 然后回车
  4. 听到「扩展」相关内容即到达。这是浏览器的扩展管理页

Chrome 用户：第 3 步改为输入 chrome://extensions，其余相同。

三、打开开发人员模式并加载插件

  1. 在扩展页上反复按 Tab，直到读屏读出「开发人员模式 开关 关闭」 （大约按 5~10 次，页面版本不同次数不同）
  2. 按空格键打开开关，听到「开发人员模式 开关 打开」
  3. 继续按 Tab，找到「加载解压缩的扩展」按钮，按回车
  4. 弹出文件夹选择对话框。用方向键和回车进入你解压的位置， 找到并选中 extension 文件夹（只选中，不要进去）
  5. 按 Tab 到「选择文件夹」按钮，回车
  6. 等待几秒，听到扩展卡片出现（含「数学公式无障碍学习助手」字样）即安装成功

选错文件夹会提示「清单文件缺失」：说明选到了 extension 的外层或内层， 重新加载并选中恰好叫 extension 的那一层即可。

四、验证安装成功

  1. 在任意网页按 Ctrl+Shift+M，右侧弹出助手侧边栏， 读屏会读出「数学公式无障碍学习助手」标题和状态提示；若读屏没声音，按一次 Tab 把焦点移进侧边栏即可
  2. 再按一次浏览器工具栏上的插件图标可关闭侧边栏
  3. 插件默认已连好云端服务，不需要任何配置。如果听到「无法连接理解服务」：先检查网络； 同时焦点会落在「恢复默认云端服务」按钮上，按回车即可一键恢复；仍不行就联系开发者 （本机服务由开发者远程协助安装）

五、更新插件（收到新版本压缩包时）

  1. 解压新压缩包，覆盖原来的 extension 文件夹
  2. 打开扩展管理页（第二节步骤）
  3. Tab 到「数学公式无障碍学习助手」的扩展卡片，找到「重新加载」（或刷新图标按钮），回车
  4. 按 Ctrl+Shift+M 验证新版本可用

六、卸载插件

扩展管理页中 Tab 到插件卡片，找到「删除」按钮回车并确认。 历史记录会一并清除（历史只存在本机浏览器里）。

常见问题

问：按 Ctrl+Shift+M 没反应？
可能快捷键被其他软件占用。打开 edge://extensions/shortcuts （Chrome 为 chrome://extensions/shortcuts），找到本插件， 把快捷键改成例如 Ctrl+Alt+M。
问：读屏读不到侧边栏内容？
先确认焦点在侧边栏内：按几次 Tab 或 Esc 后再 Tab。Edge 侧边栏对 NVDA 支持良好； 若仍有问题请记录 NVDA 版本反馈给开发者。
问：安装时提示「无法加载扩展：清单文件缺失或不可读取」？
九成是第三步第 4 点选错了文件夹层级，重新选择恰好名为 extension 的文件夹。
问：提示「此扩展不受支持」？
确认用的是 Edge 或 Chrome 桌面版（不是手机浏览器）。
