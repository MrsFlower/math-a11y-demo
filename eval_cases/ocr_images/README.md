# OCR 真实验收记录（第三阶段）

## 图片清单与结果

### 1. `ocr_quadratic_screenshot.png` — 清晰截图：求根公式

- 原始公式：`x = \frac{-b \pm \sqrt{b^2-4ac}}{2a}`
- 识别结果：`X = \frac{-b \pm \sqrt{b^2 - 4ac}}{2a}`
- 能否再解析：**能**，朗读正常（「X 等于 分数，分子是 减 b 正负 根号下……」）
- 判定：**基本成功，有一处已知瑕疵**——斜体小写 x 被识别为大写 X（与此前
  ocr_e2e_test 观察一致，属 qwen3-vl-plus 的稳定行为）。不影响结构和讲解，
  但严格场景下大小写敏感（如区分变量 x 与矩阵 X）时需要用户复核。

### 2. `ocr_defint_screenshot.png` — 清晰截图：定积分

- 原始公式：`\int_{0}^{1} x^2 \, dx = \frac{1}{3}`
- 识别结果：`\int_{0}^{1} x^{2} \, dx = \frac{1}{3}`
- 能否再解析：**能**，朗读正常（「积分，下限 0，上限 1，x 的平方 d x 等于 三分之一」）
- 判定：**完全成功**，仅上标写法差异（`x^2` → `x^{2}`），语义等价。

### 3. `ocr_sqrt_photo.jpg` — 模拟手机拍摄：勾股定理根式

- 原始公式：`c = \sqrt{a^2 + b^2}`
- 图片条件：倾斜 3.5 度 + 米色纸面 + 侧光阴影渐变 + 传感器噪点 + JPEG 压缩 + 降分辨率
- 识别结果：`c = \sqrt{a^2 + b^2}`
- 能否再解析：**能**，朗读正常
- 判定：**完全成功**。注意：这是程序模拟的「手机拍摄」（旋转/阴影/噪点均为合成），
  不能替代真机实拍。真实手机拍摄（对焦不实、透视畸变、手写体）待用户实拍后补测。
