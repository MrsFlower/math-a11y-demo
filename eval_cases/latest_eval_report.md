- 公式名：牛顿第二定律（根据结构推断）（领域：经典力学；置信度：low；来源：llm）
- 用途：用来定量描述力、质量和加速度三者之间的因果关系，即已知物体的质量和想要的加速度时，计算需要施加多大的力；或者已知受力情况，预测物体会如何改变运动状态。
- 直觉：这个公式的核心思想是，想要改变一个物体的运动快慢或方向，必须施加外力。物体越重，也就是质量越大，它就越 stubborn，越难被推动，因此需要更大的力才能产生同样的加速效果。力是原因，加速度是结果，而质量则是衡量物体抵抗这种改变的惯性大小。
- 变量数：3；概念层数：3
- 关键词命中：2/2
- 疑似过度自信：无
- 无障碍总结：这是牛顿第二定律，公式读作 F 等于 m 乘以 a。它用来计算让物体产生加速度所需的力。核心直觉是：力是改变运动的原因，质量是物体抵抗改变的惯性。F 代表合外力，m 代表质量，a 代表加速度。结构上，力等于质量与加速度的乘积，意味着质量越大，产生相同加速度所需的力就越大。这是一个线性关系，描述了宏观世界中力与运动变化的基本规律。
- 样例备注：极短公式；即使认出牛顿第二定律，置信度也应被校准压低并标注推断，这是保守机制的预期表现。
### physics_heat_001：一维热传导方程
- 输入：`\frac{\partial T}{\partial t} = \alpha \frac{\partial^2 T}{\partial x^2}`
- 公式名：一维热传导方程（领域：偏微分方程 / 物理数学；置信度：high；来源：llm）
- 用途：用来描述热量（或类似扩散物质）在物体内部如何随时间推移而传播和分布，预测温度场未来的状态。
- 直觉：这个公式的核心思想是：某一点温度的变化快慢，取决于它周围邻居的温度分布是否均匀。如果某点比周围冷，热量就会流进来让它升温；如果比周围热，热量就会流出去让它降温。它揭示了平滑化趋势，即系统总是倾向于消除局部的剧烈差异，让温度分布变得更平缓。
- 变量数：4；概念层数：3
- 关键词命中：2/2
- 疑似过度自信：无
- 无障碍总结：这是一维热传导方程。它的用途是预测温度如何随时间在物体中传播。直觉上，它告诉我们：某处温度变化的快慢，取决于该处温度与周围邻居温度的差异程度。具体来说，等号左边的 T 对 t 的偏导数，表示温度随时间的变化率；等号右边的 T 对 x 的二阶偏导数，表示温度在空间上的弯曲程度，也就是局部不均匀性；中间的阿尔法是材料的热扩散率。整个公式意味着，空间上的不均匀性驱动了时间上的变化，系统总是倾向于通过热流动来抹平温度差异，最终达到均匀平衡。
- 样例备注：应讲“温度随时间的变化由空间弯曲程度驱动”。
### physics_wave_001：一维波动方程
- 输入：`\frac{\partial^2 u}{\partial t^2} = c^2 \frac{\partial^2 u}{\partial x^2}`
- 公式名：一维波动方程（领域：偏微分方程 / 物理数学；置信度：high；来源：llm）
- 用途：用来描述波（如琴弦振动、声波）在空间中如何随时间传播和演化，它建立了时间上的加速度与空间上的弯曲程度之间的联系。
- 直觉：这个公式的核心思想是：某个位置现在的“加速趋势”，取决于它周围邻居的“弯曲形状”。如果某处比两边都凸出或凹陷，它就会受到一个恢复力，从而产生加速度。右边的常数 c 的平方决定了这种影响传递得有多快，也就是波速。
- 变量数：4；概念层数：3
- 关键词命中：2/2
- 疑似过度自信：无
- 无障碍总结：这是一维波动方程。它的用途是描述像琴弦振动这样的波是如何传播的。直觉上，它告诉我们要想知道某一点下一时刻怎么动，得看它现在弯得厉不厉害。公式左边是 u 对时间 t 的二阶偏导数，表示该点的加速度；右边是 c 的平方乘以 u 对位置 x 的二阶偏导数，表示空间上的弯曲程度。这意味着，加速度是由空间的曲率驱动的，而 c 代表波速。理解的关键在于，偏导数让我们能单独分析时间变化或空间形状，而二阶导数联系了力学中的加速度与几何中的曲率。
- 样例备注：应讲扰动以速度 c 传播。
### physics_gauss_001：高斯定律（微分形式）
- 输入：`\nabla \cdot \mathbf{E} = \frac{\rho}{\varepsilon_0}`

- 直觉：想象空间中的每一个点都像是一个微小的喷泉或排水口。如果这个点有正电荷，电场线就像水一样从这里向外喷涌而出；如果有负电荷，电场线就汇聚到这里。这个公式告诉我们，电场线从某一点发散出来的强度，直接取决于这里聚集了多少电荷。电荷越密集，电场向外扩散的趋势就越强。
- 变量数：4；概念层数：3
- 关键词命中：2/2
- 疑似过度自信：无
- 无障碍总结：这是电磁学中著名的高斯定律的微分形式。它的核心思想是：电荷是电场的源头。公式左边描述了电场线从空间某一点向外发散的强度，右边描述了该点电荷的密集程度。两者通过真空介电常数联系起来，意味着某处电荷越密集，电场线从那里发散出来的趋势就越强。简单来说，它告诉我们在任何一个点上，电场的‘流出量’直接由那里的电荷量决定。
- 样例备注：应讲“电荷是电场的源”，散度读法要对。
