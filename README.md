# 数学公式无障碍学习助手

面向视障学生的数学公式无障碍学习工具：把公式「读得出来、讲得明白」。

读屏软件（如 NVDA）遇到数学公式时，往往只能逐字符读出「反斜杠 f r a c …」式的乱码。
本项目把网页中的公式（KaTeX / MathJax / LaTeX 源码 / 视觉符号串 / 化学式）转译成
结构化的中文读法，并可调用大模型进一步讲解公式含义——全程键盘可达、读屏闭环。

「2026 小有可为 AI 向善创新挑战赛」参赛作品，公益项目。

## 在线体验

GitHub Pages 网页体验版：<https://mrsflower.github.io/math-a11y-demo/>

1. 粘贴或点选一个公式（LaTeX、纯文本、化学式均可）
2. **转译成读屏友好文本**——确定性规则引擎把符号转成中文读法，结果逐字可复现
3. **理解并讲解**——大模型给出结构读法、公式名称与一句话理解
4. **听 AI 讲解**——百炼 Qwen-TTS 语音朗读

## 浏览器插件（完整体验）

在任意网页选中公式即可使用：

1. 将 `extension/` 目录加载为浏览器「加载已解压的扩展程序」（Chrome / Edge，Manifest V3）
2. 在侧边栏底部「服务设置」中填入后端地址与鉴权 token（FC 触发器需 Bearer 鉴权；
   代码中默认值为占位符）
3. 在任意含公式的网页上按快捷键（默认 `Alt+Shift+M`）或选中公式后点击侧边栏按钮

完整能力：三种输入路径（页面公式提取 / 选中文本 / 手动粘贴）、
诚实转译（识别不了的符号原样保留并告知）、双朗读风格、五段式 AI 讲解与追问、
忙碌状态反馈、自愈授权、诊断信息播报。全程适配 NVDA 等读屏软件。

## 后端（可选本地部署）

后端为 FastAPI 应用（`app/`），部署于阿里云百炼高代码应用：

```bash
pip install fastapi uvicorn
python deploy_starter/main.py   # 默认 http://127.0.0.1:8321
```

- 转译核心为确定性 Python 规则引擎（树优先 + 三层兜底链），同一输入任何时间复现逐字一致
- 讲解 / TTS 走通义千问系列模型，三级模型备用链自动降级
- 应用层 Bearer 鉴权防止算力滥用（token 从环境变量 `API_AUTH_TOKEN` 注入，勿提交真实密钥）
