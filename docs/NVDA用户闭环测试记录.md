## 方法学说明（重要，先读）

代理无法真实安装 NVDA 并"听"，本次用两条等效通道逼近 NVDA 的信息来源：

1. **键盘流模拟**：用 CDP `Input.dispatchKeyEvent` 发送真实 Tab/Enter 键事件（非合成 click），
   全程不用鼠标，逐步记录焦点落点——等效 NVDA 用户的键盘操作路径。
2. **无障碍语义审计**：NVDA 读到的内容 ≈ 无障碍树的 name/role + aria-live 区域文本。
   逐项检查了：单选按钮可见文本标签、fieldset/legend 分组名、输入框 label 关联、
   状态区 `role=status` + `aria-live=polite`、结果区 aria-label。

**能证明的**：键盘可达性、焦点管理、读屏所需语义信息是否存在且正确。
**不能证明的**：NVDA 实际语音的断句/语调体验、物理 Alt+M 与 NVDA 手势的冲突、
菜单键在用户键盘上的实际行为。这些列入文末「真人复核清单」。

## 总结

- **是否能完成最小闭环：能。** 纯键盘完成「Tab 展开手动粘贴 → 输入 ∫f(x)e^(−iωx)dx →
  Enter 转译 → 焦点自动落在复制按钮 → Enter 复制 → 剪贴板内容正确」，全程无需鼠标。
- **最大阻塞点：无功能性阻塞。** 体验层遗留两项：转译太快时「正在转译」中间态播报
  可能被完成播报盖过（本地规则引擎 <1 秒）；紧凑模式 `e^(-iωx)` 读屏逐字符读会偏碎
  （这正是结构朗读档存在的理由，默认档已规避）。
- **最需要立即修的问题：无高危问题。** 中低危见问题清单。
- **红线核验**：`∫f(x)e^(−iωx)dx` 结构朗读输出「对 f(x) 乘以 e 的 负 i 欧米伽 x 次方，
  关于 x 积分」——未原样返回，无符号天书。**红线通过。**

## 场景 A：手动粘贴闭环

- 是否通过：**通过**（纯键盘）
- 操作过程：Tab×2 依次落在「转译原文，不解释」（已选中）→「结构朗读」（已选中）；
  继续 Tab 经「提取本页公式」「使用选中内容」到「手动粘贴（兜底）」summary，Enter 展开；
  Tab 进输入框（名称「题目、公式、化学式或 LaTeX」），输入红线公式；Tab 到「开始转译」Enter。
- NVDA 等效播报（aria-live 文本）：
  - 完成时：「转译完成。置信度：高。焦点在『复制转译结果』按钮，按回车复制；也可保存到历史或转去理解模式。」
  - 复制后：「转译结果已复制到剪贴板。」
- 焦点管理：转译完成后焦点自动落在「复制转译结果」按钮（验证 activeElement=transcribe-copy-btn），
  回车即复制，剪贴板内容与转译结果逐字一致。
- 问题：本地规则转译 <1 秒，「正在转译（…结构朗读）」中间态可能被直接跳过——
  对用户无害（直接听到完成播报），但 LLM 路径慢时中间态仍在。
- 建议：无需修改。若要保证中间态可听，可给状态播报加最小停留时长，暂不做。

## 场景 B：选中网页内容后送入插件

- 是否通过：**链路通过**（捕获投递 → 面板接收 → 自动转译）；物理 Alt+M 待真人复核
- 操作过程：测试页已补「视觉公式纯文本」段（plugin_test_page.html 第 7 节，4 个样例）。
  程序化选中「样例一」段落（键盘等效），经 background 同款 deliverCapture 等价路径
  （storage.session + runtime capture 消息）投递到面板：面板自动走转译流程，
  输出「对 f(x) 乘以 e 的 负 i 欧米伽 x 次方，关于 x 积分」。
- 关键点：视觉公式（含 ∫、−、ω）**未被 looksLikeLatex 误判**，未强制进 LaTeX 确认，直接转译。
- 问题：Alt+M 的物理按键行为与 NVDA 手势是否冲突无法自动化验证。
- 建议：真人复核 Alt+M；若冲突，manifest commands 可换键（如 Alt+Shift+M）。

## 场景 D：紧凑文本模式

## 场景 E：理解模式切换

- 是否通过：**通过**
- 操作过程：转译完成后 Enter「转去理解模式」→ 单选自动切「理解公式，可追问」→

  朗读预览自动到达：「积分 f 左括号 x 右括号 e 的 减 i 欧米伽 x 次方 d x」。
- NVDA 等效播报：「转译结果转理解（已自动转换）捕获成功，正在生成朗读预览。
  焦点已在『确认并分析』按钮，按回车开始分析；需修改请按 Shift+Tab 进入编辑框。」
- 问题：无。切换后用户明确知道下一步（播报含焦点指引）。
- 建议：无。
