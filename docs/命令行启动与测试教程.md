# 命令行启动与测试教程（Windows PowerShell）

面向：第一次在本机把「数学公式无障碍学习助手」跑起来并验证效果的人。
全程只需要 PowerShell，一行一行照抄即可。每一步都附上「预期看到什么」。

> 前提：本机已安装 Python 3.10+（本项目在 3.14 上开发）。
> Node.js 是可选项，只有想体验 B 路线（SRE 对照组）才需要。

## 第 3 步：启动服务

```powershell
python -m uvicorn app.main:app --port 8321
```

**预期**（几秒内出现）：

```
INFO:     Started server process [xxxxx]
INFO:     Application startup complete.
INFO:     Uvicorn running on http://127.0.0.1:8321 (Press CTRL+C to quit)
```

这个窗口要**保持开着**（它就是服务器）。停止服务：在该窗口按 `Ctrl+C`。

> 为什么用 8321：本机 8000 端口已被其他程序占用。想换端口改 `--port` 后面的数字即可。
> 如果报 `winerror 10048`，说明该端口也被占了，换一个数字（如 8322）。

## 第 4 步：验证服务活着（另开一个 PowerShell 窗口）

```powershell
Invoke-RestMethod http://127.0.0.1:8321/api/health | ConvertTo-Json -Depth 5
```

**预期**：一段 JSON，重点看三个字段——

- `"ok": true` → 服务正常
- `llm.available: true` → Key 生效，走真实大模型（false 则走本地规则兜底）
- `llm.model` → 当前生效的模型（默认 `qwen3.7-plus`）

## 第 5 步：命令行直接测一条公式

以求根公式为例（PowerShell 写法，注意 JSON 里反斜杠要双写）：

```powershell
$body = '{"latex": "x = \\frac{-b \\pm \\sqrt{b^2-4ac}}{2a}"}'
$r = Invoke-RestMethod -Uri http://127.0.0.1:8321/api/parse-latex -Method Post -Body $body -ContentType "application/json; charset=utf-8"
$r.speech_text
$r.explanation.overview
$r.explanation.layers | Format-List title, content
```

**预期**：
- `speech_text`：「x 等于 分数，分子是 减 b 正负 根号下 b 的平方 减 4 a c，根号结束，分母是 2 a，分数结束」
- `overview`：一句话总览（有 Key 时来自大模型）
- `layers`：3-5 层由外到内的分层讲解

再试一条物理公式（验证导数/点记号的语义化朗读）：

```powershell
$body = '{"latex": "\\rho c_p \\frac{\\partial T}{\\partial t} = \\nabla \\cdot ( k \\nabla T ) + \\dot{q}"}'
(Invoke-RestMethod -Uri http://127.0.0.1:8321/api/parse-latex -Method Post -Body $body -ContentType "application/json; charset=utf-8").speech_text
```

**预期**：「柔 c 下标 p T 对 t 的偏导数 等于 散度 左括号 k 梯度 T 右括号 加 q 点」
（导数不会读成"分数"，`\dot{q}` 读"q 点"，`∇⋅` 读"散度"——这是 A 路线的核心卖点。）

再试语音合成（需要 Key，生成的 wav 可双击播放验听）：

```powershell
$body = '{"text": "分数线上面是 F，下面是 A，整体表示单位面积上的力。"}'
Invoke-WebRequest -Uri http://127.0.0.1:8321/api/tts -Method Post -Body $body -ContentType "application/json; charset=utf-8" -OutFile tts_test.wav
Get-Item tts_test.wav | Select-Object Name, Length
```

**预期**：生成几百 KB 的 `tts_test.wav`，Cherry 音色中文女声。前台对应 Web 页/侧边栏的「听 AI 讲解」按钮。
验完可删：`Remove-Item tts_test.wav`。

再试理科符号转译（第五阶段，规则路径无需 Key，不解释只转符号）：

```powershell
$body = '{"text": "∫f(x)e^(−iωx)dx", "profile": "spoken_structured", "engine": "rules"}'
(Invoke-RestMethod -Uri http://127.0.0.1:8321/api/transcribe-symbols -Method Post -Body ([System.Text.Encoding]::UTF8.GetBytes($body)) -ContentType "application/json; charset=utf-8").transcribed_text
```

**预期**：输出类似“对 f(x) 乘以 e 的负 i 欧米伽 x 次方，关于 x 积分”，没有任何公式用途解释和客套话。
前台对应插件侧边栏默认的「转译原文」模式与 Web 页顶部「符号转译」区。

7. 引擎选「对比」→ 看 A 路线中文 vs B 路线英文 MathSpeak 的差距

## 常见问题排查

| 现象 | 原因与处理 |
|---|---|
| 启动报 `winerror 10048` | 端口被占，换 `--port 8322` |
| `llm.available: false` | `.env` 缺失或 Key 没填；确认后**重启服务**（改 .env 必须重启才生效） |
| 解释来源是 `rules` 不是 `llm` | 同上；或 Key 额度用尽且备用链耗尽（看服务器窗口的报错） |
| 大模型返回 403 | 单个模型免费额度用尽，系统会自动切备用链，无需处理；全链耗尽才需要换模型名 |
| PowerShell 输出中文乱码 | 先执行 `[Console]::OutputEncoding = [Text.Encoding]::UTF8`（服务端已声明 utf-8，若仍乱码多半是控制台编码问题） |
| OCR 报错 400 | 图片格式不支持或不是真实图片；用 png/jpg 的公式截图重试 |
| B 路线（SRE）不可用 | 没装 Node 依赖，执行 `cd sre; npm install; cd ..`；不影响 A 路线 |
