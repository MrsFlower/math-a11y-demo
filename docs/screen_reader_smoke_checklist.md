# 读屏冒烟检查清单（NVDA 优先，第四阶段）

> 用法：开 NVDA（或系统讲述人）走一遍 http://127.0.0.1:8321 ，逐项打勾。
> 每项都是可判定的检查动作，不是原则。检查人：____ 日期：____

## 页面骨架与导航

- [ ] 打开页面，NVDA 先读到页面标题「数学公式无障碍学习助手」。
- [ ] 按 H 键能依次跳到：第一步输入公式 → 第二步分析结果 → 短讲解 → 详细讲解 → 继续追问。
- [ ] 顶部 4 个跳转链接（输入区/短讲解/详细讲解/追问）Tab 可达、回车后焦点确实移动到目标区。
- [ ] 全页 Tab 顺序：跳转链接 → 方式一 LaTeX 框 → 分析按钮 → 方式二文件控件 → …… → 追问输入框，无跳跃或死循环。

## 输入区（4 个入口）

- [ ] 方式一：LaTeX 输入框有可读 label，placeholder 不被当成值读出。
- [ ] 方式二：文件选择控件读出「选择图片文件（png / jpg / webp / bmp，8MB 以内）」。
- [ ] 方式三：普通文本框 label 和提示（会填入方式一，需确认）都能读到。
- [ ] 方式四：示例按钮读出「填入示例公式：xxx」+ 提示语。
- [ ] 「解析路线」折叠区（details）能用回车展开/收起，展开后 3 个单选可用方向键选择。

## 分析等待与取消

- [ ] 点「分析公式」后按钮变为禁用态（NVDA 读出「不可用」）。
- [ ] 状态区自动播报「正在分析，通常需要 20 秒左右」（aria-live，不需要移动焦点）。
- [ ] 「取消本次分析」按钮出现且 Tab 可达；按下后播报「本次分析已取消」，分析按钮恢复可用。
- [ ] 分析完成后播报「分析完成……」，焦点自动落到「第二步：分析结果」标题。

## OCR 确认流程

- [ ] 识别中/成功/失败均在 OCR 状态区自动播报（无需焦点移动）。
- [ ] 识别成功后焦点自动落到「识别出的 LaTeX」编辑框，可直接键盘修改。
- [ ] 三个按钮名称完整可读：「确认识别结果并开始分析」「重新选择一张图片」「只复制识别出的LaTeX，不分析」。
- [ ] 上传非图片文件，播报的错误里含下一步建议（换清晰截图 / 改用粘贴）。
- [ ] 「重新选择图片」后播报已清除，焦点回到文件控件。

## 结果区（短讲解 / 详细讲解）

- [ ] 短讲解默认可见：公式名（含领域、置信度徽章文字）、一段话总结、用途、直觉、变量说明依次可读。
- [ ] 变量说明是真表格：NVDA 表格导航（Ctrl+Alt+方向键）能按 符号/角色/含义 列读。
- [ ] 三个 `<details>` 折叠区（概念与误解 / 结构讲解 / 原始 LaTeX 与 MathML）读出「摘要 折叠/展开」状态，回车可切换。
- [ ] 折叠区默认收起，页面初始不铺满全部内容。
- [ ] 置信度低时读出「置信度：低（根据结构推断）」。

## 结构树与追问

- [ ] 结构树每个节点的「追问此部分」按钮读出「追问这一部分：xxx，内容是 xxx」——知道追问的是哪一部分。
- [ ] 按下后播报「当前聚焦：xxx。你的下一个问题将针对这一部分」，焦点移到追问输入框。
- [ ] 推荐问题按钮读出「使用推荐问题：xxx」。
- [ ] 回答生成后 aria-live 区域自动读出回答内容。

## 历史记录

- [ ] 历史是真表格（时间/公式/操作三列），表格导航可用。
- [ ] 「重新载入」「复制总结」按钮的 aria-label 含公式名，能区分是哪条记录。
- [ ] 「清空历史」先弹确认对话框，确认框内容可读，取消后记录仍在。
- [ ] 清空后播报「历史记录已清空」，区域显示「暂无记录」。

## 复制与朗读

- [ ] 5 个复制按钮名称互相可区分：短讲解 / 详细解释 / LaTeX / MathML / 纯文本全集。
- [ ] 任一复制按下后播报「xx已复制到剪贴板」。
- [ ] 「朗读公式」「停止朗读」可用，系统语音与 NVDA 不互相卡死（先停 NVDA 语音再听）。

## 已知边界（检查时不算失败，记录即可）

- OCR 对斜体小写 x 可能识别为大写 X，需人工确认。
- 普通文本转换置信度低时必须出现「请检查识别结果」类提醒。
