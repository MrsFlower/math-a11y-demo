## 一、目标

把「数学公式无障碍学习助手」的网页体验版 demo 页面发布到 GitHub Pages，
得到一个**任何人都能直接打开的链接**，作为参赛材料的「在线体验」入口。

背景：后端 API 部署在阿里云（有鉴权），页面已做好跨源调用适配，
只要页面本身能被浏览器正常渲染，功能就能跑通。

## 二、要上传的文件（只有这三个）

源目录：`gh_pages_upload\`（相对本仓库根目录，即 `..\gh_pages_upload\`）

| 文件 | 说明 |
|---|---|
| `index.html` | 首页（项目介绍 + 体验入口按钮），Pages 根目录会自动展示它 |
| `demo.html` | 体验页本体，含调用云端 API 的逻辑 |
| `README.md` | 仓库首页说明 |

**不要上传其他任何文件。** 尤其不要把整个 math-a11y-assistant 目录推上去
（见第五节敏感文件清单）。

## 三、操作步骤

1. 登录 GitHub → 右上角 + → **New repository**
   - Repository name：`math-a11y-demo`（或任意喜欢的名字，记住它）
   - 可见性：**Public**（必须公开，Pages 免费版只支持公开仓库）
   - 勾选 Add a README（之后会覆盖）
2. 进入仓库 → **Add file → Upload files** → 把上面两个文件拖进去 → Commit
3. 开启 Pages：仓库 **Settings → Pages**
   - Source / Branch：选 `main`，目录 `/ (root)` → **Save**
4. 等 1~2 分钟，页面顶部出现绿色提示，链接形如：
   `https://<用户名>.github.io/math-a11y-demo/`
5. **验证**（必做）：
   - 打开 `https://<用户名>.github.io/math-a11y-demo/` → 应看到深蓝底的项目首页，
     点「立即体验网页版」能跳到 demo 页
   - 直接打开 `https://<用户名>.github.io/math-a11y-demo/demo.html` → 页面应正常渲染
     （不是下载、不是空白）
   - 点「求根公式」示例 → 点「转译成读屏友好文本」→ 几秒后应出现
     「x 等于 负 b 加减 根号下 b 的平方 减 4ac 除以 2a」之类的中文读法
   - 如果报 401/连接失败：联系项目负责人（可能是云端部署未同步，与你无关）
6. 把验证通过的完整链接发回。

## 五、敏感文件清单（红线）

**本次只传两个文件，天然不会泄露。但将来若有人想把整个仓库开源，
以下文件/内容绝不能出现在公开仓库：**

| 文件/内容 | 原因 |
|---|---|
| `.env` | 含百炼大模型 API Key（LLM_API_KEY / DASHSCOPE_API_KEY），泄露即被盗刷额度 |
| `dist\*.whl`、`build\`、`*.egg-info` | 打包产物，含后端全部源码，无需公开 |
| `docs\交付待办.md` 等内部文档 | 含内部地址、token、待办策略 |
| `photo\` | 个人截图 |
| `.workbuddy\`（工作区根目录） | 会话记忆，可能含密钥上下文 |
| `scripts\_rec_*.py`、`_diag_*.py` | 内部诊断脚本，含内网地址与调试细节 |

**可以公开的敏感项说明**：`demo.html` 与插件里的 Bearer token 是
客户端共享密钥（防算力滥用用），本就要随插件分发，公开无妨；
真正不能泄露的是 `.env` 里的大模型 API Key。
