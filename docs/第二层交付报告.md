## 关键问题定位与修复(本轮最大收获)

**现象**:质量测试初跑时 5 例中 4 例解释回落到本地规则(`source=rules`),尽管 Key 有效。

**定位**:绕过 API 直接测 LLM 链路,发现 `qwen3.7-plus` 是混合思考模型,默认开思考,
生成完整 JSON 需 46~60+ 秒,恰好撞上 60s 读超时——3 例超时、2 例擦线通过。

**修复**(`app/llm.py`):
1. 请求体加 `enable_thinking: false`(讲解任务不需深度推理)→ **延迟 46~60s 降至 18~22s,5/5 稳定成功**;
2. 读超时 60s → 120s 兜底;
3. 防御:接入点若不认该参数(400)自动去参重试并记住。

**连带修正**:超时解决后暴露验收词表过死——大模型用「因为/代表/就像」等同样在讲「为什么」,
不应判为流水账。prompt 加软引导 + 词表补充等价解释词,双向对齐。
