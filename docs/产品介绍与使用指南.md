# 数学公式无障碍学习助手 · 产品介绍与使用指南

本文档面向视障用户（读屏用户）编写，全程只需键盘操作。
文档分两部分：第一部分介绍产品是什么，第二部分是一步步的使用教程。

---

# 第一部分：产品介绍

## 这是什么

「数学公式无障碍学习助手」是一个浏览器插件，帮助视障学生处理数学、物理、化学中的
理科符号。它解决两个问题：

1. **读得出来**（转译模式）：屏幕阅读器读不懂 `∫f(x)e^(−iωx)dx` 这样的符号串，
   本工具把它转成完整的中文句子：「对 f(x) 乘以 e 的 负 i 欧米伽 x 次方，关于 x 积分」。
   转译结果可以直接听，也可以复制回文档。
2. **学得明白**（理解模式）：不只是念出来，还能讲解这个公式是什么、解决什么问题、
   每个变量什么意思，并且支持继续追问，就像有位老师坐在旁边。

## 适合谁

- 使用 NVDA、争渡等读屏软件的学生与家长
- 低视力用户（可用「紧凑文本」风格，放大后阅读）
- 任何需要把 LaTeX 或视觉符号变成可读文字的人

## 它能处理什么

- 数学公式：根号、分数、上下标、积分、极限、集合、几何符号
- 化学式与反应式：H2O、SO4^2-、2H2+O2=2H2O
- LaTeX 源码：`\frac{a}{b}`、`\int_0^1 x^2 dx`
- 混在题目文字里的公式：整段粘贴进来，自动识别

## 两种工作模式

| 模式 | 用途 | 速度 |
|---|---|---|
| 转译模式（默认） | 把符号变成可读纯文本，不解释 | 快，常见符号本地规则秒转 |
| 理解模式 | 讲解公式含义，支持追问 | 需要联网调用 AI，约几秒到十几秒 |

## 隐私说明

- 你输入的文字会发送到理解服务（云服务或本机服务，取决于安装时的配置）；
  理解模式会进一步调用阿里云百炼 AI 接口
- 历史记录只保存在你自己电脑的浏览器里，不会上传
- 不收集账号、不收集浏览记录

# 第二部分：使用指南

## 第 0 步：收到压缩包，先解压（只需做一次）

你收到的是一个名为「公式助手_用户交付包_日期.zip」的压缩包，
里面装着插件和所有文档。先解压再使用：

1. 在文件资源管理器里找到压缩包，按菜单键（或 `Shift + F10`）
2. 选择「全部解压缩」，回车确认，默认解压到当前位置即可
3. 解压后得到一个「公式助手」文件夹，里面有：
   - `extension` 文件夹（插件本体，安装插件时选它）
   - 快速开始.txt、本指南、安装指引、隐私政策、测试反馈表

> 记住解压位置（例如「桌面」），后面安装插件时要回到这里选文件夹。

## 第 1 步：准备工作（只需做一次）

### 1.1 配置理解服务（什么都不用装，也不用配）

插件默认已连好开发者部署的云服务，**你的电脑不需要安装任何环境，
也不需要填任何地址**，这一步直接跳过，装完插件就能用。

> 本机服务模式：仅用于云服务不可用等特殊情况，由开发者远程协助
> 在你的电脑上安装（独立文件夹和启动方式，不在本压缩包里），
> 你不用自己找或自己装。

### 1.2 加载浏览器插件

以 Edge 或 Chrome 为例（两者步骤一致）：

1. 打开浏览器，按 `Ctrl + Shift + A`（Edge）或在地址栏输入 `chrome://extensions` 回车（Chrome）
2. 找到「开发人员模式」开关并打开。提示：在 Edge 中按 Tab 若干次直到听到
   「开发人员模式 开关 关闭」，按空格打开
3. 找到「加载解压缩的扩展」按钮并回车，在弹出的文件夹选择框中，
   进入第 0 步解压出的「公式助手」文件夹，选中 `extension` 文件夹，回车确认
4. 听到「已加载扩展」相关提示即安装成功。以后每次打开浏览器插件自动可用，不用重装

### 1.3 打开助手侧边栏

在任意网页上按 `Ctrl + Shift + M`，右侧会打开助手侧边栏。
侧边栏打开时你会听到顶部状态区的欢迎提示。再按一次工具栏图标可关闭侧边栏。

---

## 第 2 步：三十秒上手（粘贴 → 转译 → 复制）

这是最常用的最小闭环，全程只用 Tab、回车和粘贴键：

1. 按 `Ctrl + Shift + M` 打开侧边栏
2. 按 Tab 进入粘贴输入框（名称是「手动粘贴需要转译的公式」），
   按 `Ctrl + V` 粘贴内容。例如粘贴：`∫f(x)e^(−iωx)dx`
3. 按 Tab 到「转译粘贴的公式」按钮，按回车
4. 状态区会播报「转译完成。置信度：高」，此时**焦点已自动落在「复制转译结果」按钮**，
   直接按回车即可复制
5. 到记事本或作业文档按 `Ctrl + V` 粘贴，得到：
   「对 f(x) 乘以 e 的 负 i 欧米伽 x 次方，关于 x 积分」

> 提示：面板顶部的状态区是「实时播报区」，每一步的结果都会自动读出来，
> 不确定进行到哪一步时，把光标移到页面顶部附近听状态区即可。

## 第 3 步：选择转译风格

转译有两种输出风格：

- **结构朗读**（默认，推荐读屏用户）：输出完整中文句子，听起来自然
- **紧凑文本**（推荐低视力用户或复制回文档）：输出紧凑 Unicode，
  如「积分 f(x) × e^(-iωx)dx」

切换方法：转译结果出来后，焦点附近就有「换朗读风格」按钮，
回车立即按另一种风格重新转译并播报新结果；不习惯再按一次即可换回。
若想在快捷键默认行为里固定风格，展开「练习与快捷键设置」修改。

## 第 4 步：从网页把内容送进助手（三种方式）

不用手动复制粘贴的三种送入方式：

### 方式一：选中后按 Ctrl+Shift+M（推荐）

1. 在网页上用 Shift + 光标键选中一段含公式的文字
2. 按 `Ctrl + Shift + M`，侧边栏打开并自动开始转译，几秒后听到「转译完成」

### 方式二：右键菜单

1. 选中文字后按菜单键（或 `Shift + F10`）
2. 按字母键或用光标找到「用公式助手处理选中内容」，回车
3. 侧边栏打开并自动处理

### 方式三：面板内「使用选中内容」按钮

打开侧边栏后 Tab 到「使用选中内容」按钮回车，效果同上。
适合快捷键被其他软件占用时的备用方案。

## 第 5 步：理解模式（让公式学得明白）

转译只负责「读出来」；想弄懂公式，直接走讲解链路：

1. 打开侧边栏后 Tab 到「自动提取页面所有公式」按钮回车，
   插件会扫描当前网页的所有公式
2. 听到「找到的公式」列表后，**按数字键 1~9 直接选对应公式**，或 Tab 逐条选择
3. 进入「识别结果需要确认」：插件先把识别结果读给你听（朗读预览），
   焦点已落在「确认并讲解」按钮——确认无误直接回车；
   若识别有误，按 Shift+Tab 进入编辑框修改后再回车
4. 等待约 5~20 秒，听到「讲解完成」后，面板给出讲解内容：
   「这是什么公式」「一段话总结」「它用来解决什么问题」「直觉解释」「变量说明」
5. 想听声音版：Tab 到「听 AI 讲解」按钮回车，再按一次停止
6. 想继续问：Tab 到「你的问题」输入框，输入问题（如「为什么分母不能为零」），
   Tab 到「发送追问」回车，回答会自动播报

> 快捷通道：转译完成后，焦点附近就有「进一步讲解这个公式」按钮，回车即可带着刚才的
> 原文直接进入讲解，不用重新输入。粘贴的内容也可以直接点「理解粘贴的公式」。

## 第 6 步：历史记录

1. Tab 到「历史记录」回车展开
2. 历史是标准表格，读屏的表格导航键（NVDA 的 Ctrl+Alt+方向键）可逐格浏览
3. 每行有「载入」（把旧结果回填到面板）和「复制结果」两个按钮
4. 「清空历史」按钮会先弹出确认，确认后才会删除

## 第 7 步：服务设置（进阶，一般不用碰）

插件默认已连云端，正常使用不需要改这里。
Tab 到「服务设置」回车展开，可以查看或修改理解服务的地址：

- 开发者远程装过本机服务的用户：把地址改成本机服务地址，
  Tab 到「保存并测试连接」回车，听到「连接成功」即可
- 改错了想恢复：把地址清空再保存，会回到默认的云端地址

## 常见问题

**问：状态区播报「无法连接理解服务」？**
答：先检查电脑是否联网；此时焦点会落在「恢复默认云端服务」按钮上，
按回车一键回到默认云端并自动测试连接；仍不行就是云服务临时不可用，
过几分钟再试或联系开发者。

**问：转译模式里想直接讲解公式？**
答：不用切模式。粘贴的内容直接点「理解粘贴的公式」；
转译结果页有「进一步讲解这个公式」按钮；也可以直接用
「自动提取页面所有公式」进入讲解链路。

**问：在 chrome:// 或 Edge 商店页面按 Ctrl+Shift+M 没反应？**
答：浏览器安全限制，插件无法读取这类页面。请把题目复制后用「手动粘贴」。

**问：转译结果里出现「部分符号未能转换」的提醒？**
答：这是诚实提醒而不是错误。未转换的符号会保留原样列在提醒里，
系统宁可少转也不乱猜。此时可按「用 AI 重新转译」让 AI 处理，
或点「进一步讲解这个公式」走讲解链路。

**问：Ctrl+Shift+M 和其他软件快捷键冲突？**
答：在浏览器 `chrome://extensions/shortcuts`（或 Edge 的扩展快捷键设置页）
里可以修改本插件的快捷键，例如改成 Ctrl+Alt+M。

## 键盘操作速查表

| 操作 | 按键 |
|---|---|
| 打开助手面板 | Ctrl+Shift+M |
| 选中网页内容并送入 | 选中后 Ctrl+Shift+M |
| 面板内移动 | Tab / Shift+Tab |
| 切换单选按钮 | 上下光标键 |
| 展开/折叠区域（粘贴、历史、设置） | 回车 |
| 选择第 N 条公式候选 | 数字键 1~9 |

| 停止 AI 朗读 | 再按一次「听 AI 讲解」按钮 |
| 清空历史 | 「清空历史」按钮 + 确认 |
