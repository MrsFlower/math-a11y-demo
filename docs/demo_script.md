# 演示脚本（8/13 初赛视频用,目标 3-5 分钟)

> 录制前准备:`.\start.ps1` 启动服务;浏览器开 http://127.0.0.1:8321 ;
> 建议提前把 3 个公式各跑一遍预热(单次讲解约 20 秒,录制时可剪掉等待或提前生成)。
> 开场一句话:「这不是读公式工具,是面向视障学生的数学理解助手——它先讲这个公式在干什么,再讲它长什么样,而且知道自己什么时候不确定。」

---

## 第 1 段:求根公式——从「念出来」到「讲明白」(约 90 秒)

- **输入 LaTeX**:`x = \frac{-b \pm \sqrt{b^2-4ac}}{2a}`
- **点击路径**:输入框粘贴 → 点「解析并讲解」→ 页面从上往下过一遍。
- **要展示的输出亮点**:
  1. 「这是什么公式」:一元二次方程求根公式 + 领域 + 置信度徽章(high)。
  2. 「它用来解决什么问题」在最前面——先用途,不是先念结构。
  3. 变量说明表格:x/a/b/c 各有角色,a 标注「不能为零」。
  4. 概念理解层:判别式像开关,决定两个解、一个解还是没有实数解。
- **讲解话术**:
  「传统读屏只会念 x 等于负 b 加减根号下……视障同学听完还是不知道这是什么。
  我们的助手第一句话就告诉你:它是用来直接求出二次方程两个解的。
  再往下,每个字母有自己的角色,判别式为什么重要也讲清楚了。」
- **可现场追问**:「判别式小于零会发生什么?」——展示追问回答 200 字内、纯口语、无符号。

## 第 2 段:傅里叶变换——结构背后的思想(约 90 秒)

- **输入 LaTeX**:`\int_{-\infty}^{\infty} f(x)e^{-i\omega x} dx`
- **点击路径**:同上;讲解出来后重点滚动到「直觉解释」和「概念理解」两段。
- **要展示的输出亮点**:
  1. 直觉解释:把信号和不同频率的波做匹配,而不是「对 x 从负无穷积分到正无穷」。
  2. 结构层与概念层分开:结构层客观描述积分,概念层回答「为什么要这样做」。
  3. 建议听读顺序:先整体、再频率探针、再积分范围——为听觉线性化设计。
- **讲解话术**:
  「这是大学信号处理的核心公式。注意系统不只是念积分,它说:这个指数项像一个
  可调频率的探针,积分是在问『原函数里这个频率的成分有多少』。
  结构说明服务于理解,而不是替代理解。」
- **可现场追问**:「为什么积分范围是负无穷到正无穷?」

## 第 3 段:未知短公式——系统不乱装懂(约 60 秒)

- **输入 LaTeX**:`a + b = c`
- **点击路径**:同上;讲解出来后指着公式名和置信度徽章。
- **要展示的输出亮点**:
  1. 公式名带「(根据结构推断)」后缀,置信度徽章是 low,不会冒充确定命名公式。
  2. 讲法是「根据结构看,它像是在表达一种加法关系」,把判断权留给使用者。
  3. 对比:如果系统对什么都说 high,视障用户没有第二信息渠道去纠错——保守是无障碍产品的安全设计。
- **讲解话术**:
  「最后测一个陷阱:a 加 b 等于 c。它可能是勾股定理的边、可能是化学配平、什么都可能。
  系统明确说『根据结构推断,置信度低』。对看不到公式上下文的用户来说,
  一个知道自己什么时候不确定的助手,比一个什么都敢答的助手可信得多。」
- **可现场追问**:「如果我告诉你这是三角形三边关系,你怎么讲?」——展示带上下文追问后讲解升级。

## 收尾(约 20 秒)

「三个例子:会讲、讲得深、不装懂。底层是自研中文结构树朗读 + 领域模板锚点 + 置信度校准,
31 条公式样例集持续回归。我们希望它成为视障学生真正的数学理解伙伴。」
