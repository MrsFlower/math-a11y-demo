# 竞品可用性短清单（第四阶段）

> 定位提醒：我们不跟 Mathpix 拼 OCR，不跟 MathCAT/Access8Math 拼读屏插件深度。
> 差异点始终是：**中文教学型数学公式理解 Agent**。本清单只回答 4 个可用性问题，
> 用来找出我们必须补齐的基础体验，不做功能追赶。

## Mathpix（材料转换流程标杆）

1. **怎么输入**：截图快捷键、拖拽图片/PDF、手写拍照，几乎不用手写 LaTeX。
2. **怎么听/导航**：不做朗读，输出面向视觉用户（LaTeX/MathML/Word 预览）。
3. **怎么带走**：一键复制多格式（LaTeX、MathML、DOCX、Markdown），格式选择明确。
4. **出错怎么恢复**：识别结果可直接在编辑框修改后再导出；置信度低的部分高亮提示。
5. 启发：输入靠「捕获」而非「书写」；结果永远先经过「可编辑确认」再进入下一步。

## MathCAT（读屏公式朗读引擎标杆）

1. **怎么输入**：不负责输入，作为 NVDA 等读屏器的公式朗读后端，直接消费网页 MathML。
2. **怎么听/导航**：方向键逐层进出公式结构（zoom in/out），朗读风格可切换，支持盲文。
3. **怎么带走**：不负责，公式留在原文档中。
4. **出错怎么恢复**：无法解析时回退逐字符朗读，用户至少能听到原始符号。
5. 启发：结构导航「能进能出」是刚需；解析失败也要保底可听，不能沉默。

## Access8Math（NVDA 中文社区插件）

1. **怎么输入**：读网页里现成的 MathML；附带简易 LaTeX 编辑命令行，输入门槛偏高。
2. **怎么听/导航**：交互模式下按结构块导航朗读，支持中文读法定制。
3. **怎么带走**：可把公式内容导出成文字描述文档。
4. **出错怎么恢复**：非标准公式经常整体读不出，用户只能跳过，恢复手段少。
5. 启发：中文读法本地化是真实需求；「读不出就跳过」是我们要避免的死路。

## MathKicker（无障碍数学学习工作流方向）

1. **怎么输入**：面向教学材料，教师侧准备无障碍数学文档，学生侧接收。
2. **怎么听/导航**：学习场景内朗读+盲文并行，围绕「完成一次学习任务」组织。
3. **怎么带走**：产出的就是可留存的学习材料本身。
4. **出错怎么恢复**：依赖教师侧修正，学生侧自助恢复能力弱。
5. 启发：以「完成一次学习任务」为单位设计流程，而不是以「调用一次功能」为单位。

## 我们第四阶段必须补的 5 个基础体验

1. **多入口输入**：LaTeX 之外补图片 OCR、普通文本转换、示例/最近记录，输入不再只服务懂 LaTeX 的人。
2. **识别结果先确认再分析**：OCR / 文本转换结果一律先填入可编辑框并播报，用户确认后才分析（学 Mathpix 的确认流）。
3. **出错有下一步**：每条错误提示都附带补救路径（换图、改用粘贴文本等），不让用户停在死胡同（避开 Access8Math 的「读不出就跳过」）。
4. **结果可带走**：分类型复制（短讲解/详细/LaTeX/MathML/全集）+ 本地历史记录，结果能进笔记、聊天窗口和读屏器。
5. **等待可控**：长耗时分析有时长预期播报和取消按钮，用户不用对着无响应页面干等。
