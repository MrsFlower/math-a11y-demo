# 转译低置信度兜底闭环记录

更新时间：2026-08-08

## 背景

转译规则覆盖越来越广，但真实用户仍会遇到两类情况：

- 规则转译失败或残留 LaTeX 命令。
- 转译结果置信度低，需要人工核对。

此前后端已有自动兜底：默认先跑规则，规则有残留且 LLM 可用时再走大模型；大模型失败则回退规则。

问题在前端：用户只能听到“置信度低”或 warning，没有明确的下一步操作。

## 本次改动

### 后端

`app/llm.py`：

- `/api/transcribe-symbols` 返回中增加 `residue`。
- 当用户强制 `engine: "llm"` 但 LLM 不可用时，返回明确 warning：
  - `AI 重新转译当前不可用：未配置 LLM_API_KEY 或服务不可用，已返回本地规则结果。`

### 插件侧边栏

`extension/sidepanel.html` / `extension/sidepanel.js`：

- 转译结果区新增低置信度兜底区。
- 当 `confidence === "low"`、有 `warnings` 或有 `residue` 时显示。
- 兜底区操作：
  - `用 AI 重新转译`：调用 `/api/transcribe-symbols`，参数 `engine: "llm"`。
  - `手动修改或粘贴`：打开手动粘贴框，并填入本次原文。
- 若 AI 不可用，禁用 `用 AI 重新转译`，焦点转到 `手动修改或粘贴`。
- 原按钮 `转去理解模式` 改为 `进一步讲解这个公式`，降低模式感。
