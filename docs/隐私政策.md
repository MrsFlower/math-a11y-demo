# 隐私政策

应用名称：数学公式无障碍学习助手（浏览器扩展）
更新日期：2026-08-07
适用渠道：Edge 加载项商店 / 测试分发 / 源码分发

## 一、我们收集什么

**不收集任何个人身份信息。** 本扩展没有账号系统，不收集姓名、
邮箱、浏览记录、页面内容快照或设备标识。

## 二、你输入的内容去了哪里

你在侧边栏粘贴、选中或提取的公式文本，会发送到「理解服务」进行处理：

- **云端模式（默认）**：发送到开发者部署的阿里云函数计算服务，
  并进一步调用阿里云百炼（通义千问）大模型接口完成讲解、语音合成
  等能力。该链路仅传输你提交的公式文本本身，不附带任何账号或身份信息。
- **本机模式（可选，需开发者远程安装）**：发送到你自己电脑上运行的
  本地服务（127.0.0.1:8321），不出本机。

**请不要输入与公式无关的个人敏感内容**（如密码、证件号），
因为理解模式下文本会交由大模型处理。

## 三、本地存储

- 历史记录、服务地址设置仅保存在**你自己电脑的浏览器本地**
  （chrome.storage / localStorage），不会上传到任何服务器。
- 卸载扩展或点击「清空历史」即可彻底删除。

## 四、第三方服务

- 阿里云百炼（DashScope）：用于理解模式的公式讲解、OCR 识别与
  语音合成。文本按上述方式传输，处理完成后不被本应用留存。
  其数据处理条款见阿里云官方隐私政策。

## 五、权限说明（为什么需要这些浏览器权限）

| 权限 | 用途 |
|---|---|
| sidePanel | 在侧边栏展示助手界面 |
| activeTab / scripting | 读取你在当前页面**主动选中**的文字、提取页面公式 |
| contextMenus | 右键菜单「用公式助手处理选中内容」 |
| storage | 在本机保存历史记录与服务地址 |
| 主机权限（127.0.0.1:8321、*.fcapp.run） | 与本机理解服务 / 云端服务通信 |

扩展**不会**在你不操作时读取页面内容，不会修改页面，不注入广告。

## 六、未成年人

本应用面向学生群体（含未成年视障学生）。除公式文本的处理链路外，
不收集任何未成年人个人信息。

## 七、政策变更与联系方式

政策如有变更将更新本文档日期与内容。
问题反馈与数据删除请求：请联系项目开发者（提交渠道见商店页面说明）。
