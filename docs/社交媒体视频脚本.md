# 社交媒体项目介绍视频脚本（小红书主版 · 60-90 秒）

> 定位：**面向短视频平台的整体项目介绍**，不是功能教程。
> 叙事主线：让观众「听到问题」→「看到解法」→「相信做这件事的人」。
> 核心原则（与最初讨论定稿一致）：AI 动画只做氛围外壳，**真实读屏音 + 真实录屏**做内核；
> 不煽情、不演痛苦；视频本身必须无障碍（全程大字幕、高对比）。
>
> 与参赛表单视频的关系：表单「项目展示视频」建议交 NVDA 实操版
> （见 `docs/展示视频脚本.md`）；若只录一条，交本版本也可（内含真实录屏段）。

---

## 一、分镜总表

| 段落 | 时长 | 画面 | 声音 | 字幕 |
|---|---|---|---|---|
| **钩子** | 0-5s | 黑屏 | 真实读屏音：公式被逐字读成乱码/直接跳过 | 大字：「这是一个视障学生每天听到的数学课」 |
| **困境铺垫** | 5-20s | AI 动画（仅氛围）：学生坐在屏幕前，手指悬在键盘上，屏幕上的公式是空白/乱码块 | 旁白或纯字幕一句事实：「读屏软件能把网页读得流畅，遇到公式却会沉默」 | 同步字幕 |
| **转折** | 20-30s | 切**真实录屏**：选中公式 → Ctrl+Shift+M → 侧边栏打开 | 清晰读出「x 分之 sin x」 | 「我们做了一个浏览器插件」 |
| **功能展示** | 30-60s | 真实录屏蒙太奇（每条 5-8 秒，见下） | 各条真实音轨 | 每条一句卖点字幕 |
| **收尾** | 60-80s | 用户原话卡 + 结束页 | 价值观一句 + BGM 收 | 反馈原话 + 比赛/开源/体验入口 |

## 二、功能展示蒙太奇（30-60s，四条各一句卖点）

1. **提取**：一键「自动提取页面所有公式」→ 数字键直选 → 「附近正文」路标定位。
   字幕：「整页公式，自动找出来」
2. **读法对比（爆点）**：同一道极限公式，旧读法「分数，分子是 sin x，分母是 x，分数结束」
   vs 新读法「x 分之 sin x」各放一句。字幕：「同一道公式，怎么读，用户自己选」
3. **讲解**：五段式讲解滚屏 + 追问一句。字幕：「不止念出来，还讲明白」
4. **忙碌状态反馈**：点「听 AI 讲解」，读屏报「正在生成音频，按钮暂时不可用，请稍候」。
   字幕：「每一次按键，都有回应」——这是视障用户真实反馈催生的功能

## 三、钩子音轨素材（最稀缺，先备）

- 首选：真实 NVDA 读练习页裸公式的录音（乱码感越强越好）；
- 备选：用 `scripts/make_voiceover.py` 同款 SAPI 语音读
  「积分号 f 括号 x 括号 e 幂 减 i …」模拟乱码听感；
- 对比音轨（转折/蒙太奇 2）：云端 TTS 生成「x 分之 sin x」清晰版。

## 四、AI 动画细化提示词（即梦）

> 生成设置：自定义比例 **9:16（1080×1920）**，每镜头 5 秒，每镜生成 2-3 条候选挑选。
> 两段实操视频的用法：**不做风格转绘**（真实录屏的真实性是本片生命线），只作三处锚点：
> ① 截「功能演示部分」视频首帧 → 模糊+提亮 → 作镜头 B 的尾帧锚点；
> ② 「乱码部分」视频只提取音轨（钩子声音），不喂给画面生成；
> ③ 若用即梦「参考视频」功能，只参考动作节奏，强度调最低。
>
> **素材分工总原则**：两段实拍原片最终都进剪辑软件（剪映等）原样使用，
> 即梦只生成动画 A/B/C；进即梦的实拍衍生物只有「功能演示首帧截图」这一张图（作尾帧）。
> 时间线：黑屏+乱码音轨 → 动画A → 动画B（尾帧=屏幕亮起）→ 硬切功能演示实拍。

### 镜头 A「沉默的公式」（困境铺垫，5s）

```
扁平插画风格，竖屏构图。画面下三分之一：一个背对镜头的学生坐在电脑显示器前，
只有背影和搭在键盘上的手，没有正脸。显示器发出冷蓝白色光，照亮学生轮廓。
画面上三分之二：大量杂乱、残缺的数学符号（∫、√、x、括号、等号）像雪一样
缓慢向上漂浮，符号半透明、大小错落。整体冷灰蓝色调，安静、略带压抑的氛围。
镜头从学生肩后缓慢向屏幕推近。画面顶部保留干净留白用于字幕。
负面提示：真实人脸、正面特写、文字、水印、剧烈动作、暖色调。
```

### 镜头 B「一次按键」（转折过渡，5s，带尾帧控制）

```
扁平插画风格，延续上一镜头的场景与配色。特写：一根手指按下键盘，
按下瞬间从指尖荡开一圈暖白色光晕。画面中漂浮的杂乱符号开始排列整齐，
汇聚成一条清晰、有序的光带横贯画面中部。镜头随光带推近，
结尾屏幕光亮逐渐充满整个画面。冷灰蓝色调中加入暖光点缀。
负面提示：真实人脸、文字、水印。
```

尾帧设置：功能演示视频首帧 → 高斯模糊 + 提亮 → 设为尾帧，
生成片段会自然收在「屏幕亮起」，剪辑时硬切直接进真实录屏，听觉转折即叙事转折。

### 镜头 C「清晰之后」（可选，收尾背景，4s）

```
扁平插画风格，同一位学生，仍是背影，姿态放松。屏幕前漂浮着整齐、
有序的公式光带，像乐谱一样平缓浮动。冷色调中加入一盏暖橙色台灯光。
镜头缓慢拉远，露出安静的深夜书桌一角。氛围平静、有希望。
画面顶部保留干净留白用于用户原话字幕。
负面提示：真实人脸、文字、水印。
```

## 五、竖屏（9:16）比例与构图策略

实操录屏是 16:9 电脑屏幕，直接塞进竖屏会上下大片空白或主体过小。两个模板解决：

| 模板 | 做法 | 适用镜头 |
|---|---|---|
| A 侧栏特写 | 从录屏裁出侧边栏竖条（天然竖构图）放大铺满 9:16 | 转折朗读、读法对比、忙碌状态、追问——声音焦点本就在侧栏 |
| B 全景居中 | 16:9 完整居中，上下用同帧模糊放大填充 | 整页提取、选中操作、练习页全景 |

- 侧边栏本就是屏幕右侧的窄竖条，裁它当主画面不是妥协，是信息密度最高的竖屏表达；
- 固定分区约定（全片统一，AI 动画同样遵守）：顶部约 12% 字幕区、底部约 18% 卖点区；
  动画提示词已预留这两块干净留白，剪辑时文字直接落位不遮主体；
- 模板 A 裁切时保留侧栏完整宽度 + 左侧露出 10% 页面内容作「来源感」锚点。

## 六、平台适配

| 平台 | 画幅 | 差异 |
|---|---|---|
| 小红书（首发） | 3:4 或 9:16 | 封面用「乱码朗读 vs 清晰朗读」对比图；标题走具体叙事，如「我们教盲人'听'懂高数公式」；正文带 Pages 体验链接 |
| 抖音 | 9:16 | 钩子前置到 0 秒，节奏加快，总长压到 60 秒内 |
| B 站 | 16:9 | 加长版 3-5 分钟：补技术向内容（树优先三层兜底、六层防线、用户共创迭代表），可复用参赛 NVDA 录屏素材 |

## 七、制作规范

- 全程大字幕（大量用户静音刷）；BGM 音量压在人声之下；
- 高对比画面；结束页放体验入口（Pages 站）与比赛信息；
- 每条录屏单独录、后期拼接，失败重来代价低。
