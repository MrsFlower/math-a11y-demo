# 数学公式无障碍学习助手

**参赛赛道：残健融合——有AI无碍**

> 一句话定位：一个让视障学生「读得出公式、学得明白公式」的浏览器 AI 助手。
> 选中网页上的公式按一个快捷键，读屏软件读不出来的理科符号，
> 立刻变成一句完整的中文；还想知道它是什么意思，AI 老师当场讲解、随问随答。

---

## 一、问题背景：公式是视障学生理科学习的「朗读黑洞」

屏幕阅读器（如 NVDA）能把网页文字读得流畅，但遇到理科符号就失灵了：

- `∫f(x)e^(−iωx)dx` 被逐字符读成「积分号 f 括号 x 括号 e 幂 减 i …」，
  结构全丢，听了等于没听；
- 网页公式常以 KaTeX/MathJax/MathML 渲染，读屏读到的是乱序的数学标记或
  干脆静默，学生连「这里有个公式」都不知道；
- LaTeX 源码 `\frac{a}{b}` 直接朗读就是噪声。

结果：视障学生在语文、历史上可以无障碍阅读，一到数学、物理、化学就被
「公式墙」挡住。市面上的读屏方案要么依赖教材提前制作盲文/语音版（滞后、覆盖窄），
要么需要专业设备。学生在做在线作业、看网课讲义这些**即时场景**里没有工具可用。

## 二、产品是什么

「数学公式无障碍学习助手」是一个 **Chrome/Edge 浏览器插件**，
以侧边栏形式伴随任何网页工作，全程纯键盘操作、读屏友好。两个核心能力：

1. **读得出来（公式转译）**：把符号串、LaTeX、化学式转成读屏可顺畅朗读的
   纯文本。`∫f(x)e^(−iωx)dx` → 「对 f(x) 乘以 e 的 负 i 欧米伽 x 次方，关于 x 积分」。
   两种风格：「结构朗读」给读屏用户听，「紧凑文本」给低视力用户看、复制回文档。
2. **学得明白（AI 讲解）**：不止念出来，还讲解公式是什么、解决什么问题、
   每个变量的含义，输出「这是什么公式 / 一段话总结 / 解决什么问题 / 直觉解释 /
   变量说明」五段式结构稿；支持**追问**（「为什么分母不能为零」），
   还可以把讲解合成为语音直接听。

输入入口覆盖真实学习场景：

| 入口 | 场景 |
|---|---|
| 选中网页文字 + 快捷键 | 网课讲义、在线作业里划到公式即处理 |
| 一键提取本页公式 | 自动扫描页面里的 KaTeX/MathJax/MathML 公式并列出候选 |
| 手动粘贴 | chrome:// 等受限页面的兜底 |
| 公式图片 OCR | 拍照/截图里的公式（视觉模型识别） |

## 三、产品亮点

### 1. 无障碍不是附加功能，是第一设计约束

- 全键盘闭环：从打开面板到复制结果，只用 Tab、回车、方向键；
  每一步完成后**焦点自动落在下一个动作按钮上**，读屏用户不用找；
- 状态区 `aria-live` 实时播报，每一步的结果都自动读出来，用户永远知道进行到哪；
- 转译、讲解结果均为纯文本，读屏朗读零障碍；历史表格支持读屏表格导航键逐格浏览；
- 用户文档本身也按读屏习惯撰写（含按键级操作教程）。

### 2. 「诚实转译」：宁可少转，不乱猜

视障用户无法目视核对结果，错误转译比不转译危害更大。
因此转译引擎输出**置信度**，规则没把握的符号原样保留并明确播报
「以下符号未能转换，请人工核对」，绝不静默猜测。

### 3. 双引擎转译：常用内容秒出，复杂内容 AI 兜底

- 本地规则引擎：常见数学/化学符号毫秒级转换，**不联网、不花额度、离线可用**；
- 大模型引擎：规则覆盖不住的复杂记号自动升级给 LLM，LLM 失败再回退规则结果。
  学生日常 80% 的公式不消耗任何 AI 额度。

### 4. 开箱即用的云端部署

后端部署在阿里云百炼高代码应用（函数计算），测试用户**零安装、零配置**：
装上插件即用，理解、OCR、语音全部走云端。

## 四、技术方案特色

```
浏览器插件（MV3 Side Panel）
  ├─ content script：页面公式捕获（KaTeX / MathJax / MathML / 选区）
  ├─ 侧边栏 UI：全键盘交互 + aria-live 状态播报
  └─ 快捷键 / 右键菜单入口
        │ HTTPS
云端后端（FastAPI on 阿里云百炼高代码 · 函数计算）
  ├─ 转译引擎：本地规则（确定性映射表）→ LLM 增强 → 规则兜底
  ├─ 讲解引擎：结构化 Prompt + 六层可靠性防线
  ├─ OCR：Qwen-VL 视觉模型链
  └─ TTS：Qwen-TTS 语音合成
```

**模型策略**：以 qwen3.7-plus 为主模型，配置三级备用链
（qwen-plus-latest → qwen3.5-plus → qwen-flash），某模型额度耗尽返回 403 时
自动切换，保障可用性；OCR、TTS 同样配置备用链。

**AI 讲解可靠性六层防线**：大模型输出不可尽信，视障用户又无法目视纠错，
因此讲解链路设置了六层防线——结构化 Prompt 约束、温度归零、输出结构校验、
残留检测、失败回退、诚实的置信度提示，把「AI 可能胡说」的风险压到产品可接受线以内。

**工程细节**：转译 API 内置 LaTeX 残留检测（输出里仍有未展开的 LaTeX 命令
即判定转译不完整并告警）；JSON 响应显式声明 charset 兼容各类客户端；
云端入口只读配置文件固定监听端口，规避函数计算运行时端口注入陷阱。

## 五、AI 向善实践：真实用户共创，不是闭门造车

项目不是「想象视障用户需要什么」，而是**与真实视障用户一起迭代**：

- 邀请了真实读屏用户作为测试伙伴，交付完整测试包（插件 + 按键级安装指引 +
  读屏友好使用指南 + 隐私政策 + 结构化反馈表）；
- 第一轮测试暴露了真问题：主流程暴露了太多开发者概念（工作模式、确认 LaTeX），
  用户想「进一步理解公式」时被打回实现流程。团队随即完成第一轮 UI 简化
  （主入口 + 折叠替代路径），并规划以「任务流」重构界面：
  首页只做一件事——把公式读出来；转译结果页一键「进一步讲解」；
  确认步骤只在识别不可靠时出现；
- 每一轮改动都通过 NVDA 读屏实测回归，确保焦点顺序、播报文案对读屏用户成立。

这个「真实用户反馈 → 重构 → 读屏回归」的闭环会持续到赛后，是产品可持续迭代的机制。

## 六、社会价值与可持续性

- **直接受益人**：使用读屏软件的中小学生、大学生及其家长——
  理科学习从「需要专人陪读念题」变成「自己随时可学」；
- **可扩展性**：插件形态不挑网站，任何有公式的网页都能用；
  规则引擎可扩展到物理、化学、编程符号；后端已具备 OCR 能力，
  下一步接入作业拍照场景；
- **可持续运营**：常用转译走本地规则零成本，AI 仅用于复杂内容与讲解；
  云端按量计费成本可控；计划开源（参与开源贡献奖评选），
  欢迎特教学校、公益组织共建符号映射表；
- **长期愿景**：从「公式无障碍」走向「理科学习无障碍」，
  让视障学生拥有和健康学生一样的理科学习入口。

## 七、快速体验

- 在线演示与练习页：项目部署于阿里云百炼高代码应用，提供含
  KaTeX/MathJax/化学式样例的练习页，可现场打开浏览器 + 读屏实测；
- 现场演示脚本：选中公式 → 快捷键转译 → 听 AI 讲解 → 追问，全程键盘 + 读屏播报。
