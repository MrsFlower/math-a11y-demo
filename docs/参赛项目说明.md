## 一、产品简介

### 1.1 问题背景：公式是视障学生理科学习的「朗读黑洞」

屏幕阅读器（如 NVDA、争渡）能把网页文字读得流畅，但遇到理科符号就失灵了：

- `∫f(x)e^(−iωx)dx` 被逐字符读成「积分号 f 括号 x 括号 e 幂 减 i …」，结构全丢，听了等于没听；
- 网页公式普遍以 KaTeX / MathJax / MathML 渲染，读屏读到的是乱序的数学标记，甚至干脆静默——
  学生连「这里有一个公式」都不知道；
- LaTeX 源码 `\frac{a}{b}` 直接朗读就是噪声；
- 教材图片、拍照作业里的公式，读屏软件更是完全无法触及。

**结果**：视障学生在语文、历史上可以无障碍阅读，一到数学、物理、化学就被「公式墙」挡住。
现有方案要么依赖教材提前制作盲文/语音版（滞后、覆盖窄），要么依赖人工陪读念题；
学生在做在线作业、看网课讲义这些**即时学习场景**里没有工具可用。

### 1.2 产品是什么

「数学公式无障碍学习助手」是一个 **Chrome / Edge 浏览器插件**，以侧边栏形式伴随任何网页工作，
全程纯键盘操作、读屏友好，后端能力部署在阿里云百炼高代码应用（函数计算），用户零安装、零配置。

两个核心能力：

1. **读得出来（公式转译）**：把符号串、LaTeX、化学式转成读屏可顺畅朗读的纯文本。
   `∫f(x)e^(−iωx)dx` → 「对 f(x) 乘以 e 的 负 i 欧米伽 x 次方，关于 x 积分」。
2. **学得明白（AI 讲解）**：不止念出来，还讲解公式是什么、解决什么问题、每个变量的含义，
   支持继续追问，可以把讲解合成为语音直接听——就像有位老师坐在旁边。

### 1.3 目标用户

- 使用 NVDA、争渡等读屏软件的中小学生、大学生及其家长（核心用户）；
- 低视力用户（可用「紧凑文本」风格放大阅读）；
- 任何需要把 LaTeX 或视觉符号变成可读文字的人（特殊教育教师、教材制作者）。

## 二、核心功能

### 2.1 读得出来：公式转译

**三条输入路径**，覆盖真实学习场景（另有右键菜单作为快捷入口的补充）：

| 输入路径 | 典型场景 |
|---|---|
| 选中网页内容 + `Ctrl+Shift+M` 快捷键 | 网课讲义、在线作业里划到公式即处理 |
| 一键提取本页所有公式 | 整页扫描 KaTeX/MathJax/MathML/正文公式，列出候选，数字键 1~9 直选；长列表配「附近正文」路标定位 |
| 手动粘贴（兜底） | chrome:// 等浏览器受限页面、外部来源的题目文字 |

**两种输出风格**，一键切换：

- **结构朗读**（默认，读屏用户）：完整中文句子，如「分数，分子是 1，分母是 2，分数结束」；
- **紧凑文本**（低视力用户 / 复制回文档）：紧凑 Unicode，如「积分 f(x) × e^(-iωx)dx」。

**覆盖符号范围**：根号、分式（含嵌套）、上下标、积分、极限、求和连乘、集合、矩阵与行列式、
分段函数、导数与点记号；化学式与反应式（H2O、SO4^2-、2H2+O2=2H2O）；
混在题目文字里的公式可整段送入自动识别。

### 2.2 学得明白：AI 讲解

- **五段式结构讲解**：「这是什么公式 / 一段话总结 / 它用来解决什么问题 / 直觉解释 / 变量说明」，
  每段独立成块，读屏可逐段浏览；
- **追问**：「为什么分母不能为零」——带着公式上下文继续问，回答自动播报；
- **听 AI 讲解**：一键把讲解合成为语音（百炼 TTS）直接听，再按一次停止；
- **讲解朗读方式设置**：「屏幕阅读器直接读」（默认）与「自动播放 AI 语音」二选一，
  未装读屏的试用者、低视力用户也能完整体验发声链路；
- **讲解前朗读预览**：识别结果先读给用户听，确认无误再开讲，识别有误可当场修改。

### 2.3 伴随能力

- **历史记录**：转译/讲解结果自动入库（同原文去重），标准表格结构，
  读屏表格导航键逐格浏览，支持载入与复制；
- **个性化分式读法**（0.8.3 新增）：读屏用户可在「结构朗读」与「紧凑读法（分母 分之 分子）」
  之间选择分式朗读风格，对下一次讲解生效——同一道公式，不同听感偏好；
- **一键诊断**：「运行诊断」生成纯文本报告（版本/环境/注入测试/服务连接），
  一键复制发给开发者，远程排障不依赖用户口述；
- **自愈授权**（0.8.1 新增）：浏览器授权失效时，面板给出「授权插件读取网页并重试」按钮，
  焦点自动落上、播报下一步指引，同意后自动重试原动作——把高频坑变成一步自助修复。

## 三、产品亮点

### 亮点 1：无障碍不是附加功能，是第一设计约束

- **全键盘闭环**：从打开面板到复制结果，只用 Tab、回车、方向键、数字键；
- **焦点接力**：每一步完成后焦点自动落在下一个动作按钮上，读屏用户永远不用找；
- **状态区 aria-live 实时播报**：每一步的结果与下一步指引自动读出来；
- **忙碌状态反馈**（0.8.3，来自真实用户反馈）：按钮进入等待时不依赖「禁用」表达状态，
  而是把文案换为进行中语义（如「生成音频中」）并播报「正在…」，
  焦点移到状态区——读屏用户听到的是「操作已受理，正在处理」，而不是不明所以的「不可用」；
- **读屏可达的文档**：安装指引与使用指南按读屏习惯撰写（按键级教程），
  并另制读屏友好的 HTML 网页版发布在文档站。

### 亮点 2：「诚实转译」——宁可少转，不乱猜

视障用户无法目视核对结果，**错误转译比不转译危害更大**。因此：

- 转译引擎输出**置信度**并如实播报；
- 规则没把握的符号原样保留，明确播报「以下符号未能转换，请人工核对」，绝不静默猜测；
- 兜底区提供「用 AI 重新转译」与「转入讲解」两条出路，低置信度也有闭环。

### 亮点 3：双引擎转译——常用内容秒出，复杂内容 AI 兜底

- **确定性规则引擎**（树优先三层兜底链，见第四节）：常见数学/化学符号毫秒级转换，
  不联网烧额度、结果可复现；
- **大模型引擎兜底**：规则覆盖不住、或输出带可疑数学残留时自动升级给 LLM，LLM 失败再回退规则结果；
- 学生日常绝大多数公式走本地规则，AI 额度只花在真正复杂的内容与讲解上，**成本可控、离线核心能力可用**。

### 亮点 4：开箱即用的云端交付

后端部署在阿里云百炼高代码应用（函数计算），测试用户**零安装、零配置**：
装上插件即用，讲解、语音全部走云端；模型密钥由平台环境变量托管，不下发到用户端。

## 四、技术方案特色

### 4.1 总体架构

```
浏览器插件（Manifest V3 · Side Panel 侧边栏）
  ├─ content script：页面公式捕获
  │    （KaTeX / MathJax / MathML / 正文纯文本公式，含读屏层清洗与选区逆解析）
  ├─ 侧边栏 UI：全键盘任务流 + aria-live 状态播报 + 焦点接力
  └─ 快捷键 / 右键菜单入口
        │ HTTPS（网关 Bearer 鉴权）
云端后端（FastAPI on 阿里云百炼高代码应用 · 函数计算）
  ├─ 转译引擎：树优先三层兜底链（语法树 → 正则规则管道 → LLM 兜底）
  ├─ 讲解引擎：结构化 Prompt + 六层可靠性防线
  └─ TTS：百炼语音合成
```

### 4.2 转译引擎：树优先三层兜底链（方案核心）

正则打补丁式的转译在「`y''` 被读成 y 的二次方」这类结构歧义上必然失效。
我们构建了分层架构，结构问题在结构层根治：

1. **第一层 · 语法树**：纯公式段走真实语法解析（LaTeX → MathML 树 → 语音/紧凑文本），
   在树上实施局部语义规则——撇号上标读导数（`y''` → 「y 二阶导数」）、
   `\frac{\partial T}{\partial t}` 读「T 对 t 的偏导数」而非「分数」、
   lim/max 下标读参数（`lim(x→0)`）、积分尾段合并（「关于 x 积分」）；
2. **第二层 · 正则规则管道**：树层不接管（混排中文散文等）时降级到 60+ 条确定性规则；
3. **第三层 · LLM 兜底**：输出仍带数学特征残留时升级大模型，失败回退规则结果。

工程防线：转译 API 内置 **LaTeX 残留检测**（输出中仍有未展开命令即判定转译不完整）；
响应显式携带 residue 残留字段供前端兜底区展示；每次发版跑 60+ 条回归断言（含极限读法守卫）。

### 4.3 朗读规则设计：为听觉认知而写

输出禁用一切 LaTeX/Markdown 符号，纯中文口语化，并遵循视障用户听觉认知习惯：

- 导数读「偏导数/导数」，点记号 `\dot{q}` 读「q 点」，向量 `\vec{u}` 读「向量 u」；
- 微分算子体现物理含义：`∇·` 读「散度」、`∇×` 读「旋度」；
- 隐式乘法显式化、幂的幂内层口语化（`-x²` 读「负 x 平方」，避免双层「次方」）；
- 输出适配读屏逐字朗读节奏，含合理停顿与结构分层；
- 分式读法可配置（结构式 / 「分母 分之 分子」紧凑式），枚举式设计为斜线式等
  用户自定义读法预留扩展位。

### 4.4 AI 讲解：六层可靠性防线

大模型输出不可尽信，视障用户又无法目视纠错，讲解链路设置六层防线：
**结构化 Prompt 约束 → 温度归零 → 输出结构校验 → 残留检测 → 失败回退 → 诚实的置信度提示**，
把「AI 可能胡说」的风险压到产品可接受线以内。

### 4.5 模型策略与可用性

- 以 qwen3.7-plus 为主模型，配置**三级备用链**（qwen-plus-latest → qwen3.5-plus → qwen-flash），
  某模型额度耗尽返回 403 时自动切换；TTS 同样配置备用链；
- 云端入口只读配置文件固定监听端口，规避函数计算运行时端口注入陷阱；
- 网关 Bearer 鉴权防刷额度；应用层再设一道鉴权中间件，双层防护。

### 4.6 页面公式捕获的鲁棒性工程

真实网页千奇百怪，捕获层经历了多轮针对性加固：

- KaTeX 无 annotation 源码层时，从视觉层 DOM **逆解析重建 LaTeX**
  （vlist 偏移分上下标、mfrac 定位分子分母）；
- MathJax v2 渲染容器为空时检查相邻 script 兄弟节点取源码；
- 选区清洗统一剥离 KaTeX/MathJax 的隐藏读屏层，杜绝「𝑓 ( 𝑥 ) f(x)」双重文本污染；
- 批量提取去重与噪声闸：整题重复块、孤立单符号噪声不进候选（高考真题页实测 21 → 17 条，零重复零噪声）。

## 五、真实用户共创：反馈驱动的迭代闭环

项目不是「想象视障用户需要什么」，而是**与真实视障用户一起迭代**：
邀请真实读屏用户（NVDA）作为测试伙伴，交付完整测试包
（插件 + 按键级安装指引 + 读屏友好使用指南 + 隐私政策 + 结构化反馈表），
每一轮改动都通过读屏等效回归验证焦点顺序与播报文案。

**「反馈 → 修复 → 读屏回归」闭环实例**（近期版本）：

| 用户反馈 | 我们的改进 | 版本 |
|---|---|---|
| 报错「此页面无法提取」却不知原因 | 五分类错误诊断 + 一键诊断报告 | 0.8.0 |
| 诊断报告显示授权从未授予（侧栏打开/切标签丢授权，高频坑） | 自愈授权按钮：焦点自动落上，同意后自动重试 | 0.8.1 |
| 高考真题页提取出整题重复块与单符号噪声 | 提取架构重构：重复块清零、噪声闸、附近正文路标 | 0.8.2 |
| 按钮禁用后读屏只报「不可用」，分不清操作是否受理 | enterBusyState：进行中语义文案 + 状态区播报 + 焦点移交 | 0.8.3 |
| 分式「分子是…分母是…」冗长，偏好「x 分之 sin x」（用户声明仅代表个人） | 分式读法设置项（默认不变、零回归），枚举式预留自定义扩展位 | 0.8.3 |

**版本演进主线**：

- **0.6.x**：云端交付打通（百炼高代码），插件内置云端地址与鉴权，用户零配置开箱即用；
- **0.7.x**：侧边栏任务流重构——删除开发者概念（工作模式、确认 LaTeX 直送），
  首页只做一件事：把公式读出来；确认步骤只在识别不可靠时出现；
  三条输入路径平铺；新增讲解朗读方式设置与等待期体验优化；
- **0.8.x**：健壮性与个性化——诊断/自愈授权、批量提取去噪、忙碌状态反馈、分式读法偏好。

这个闭环会持续到赛后，是产品可持续迭代的机制，也是「AI 向善」落在实处的证明。

## 六、下一步工作规划

已在规划中的后续方向：

1. **公式图片 OCR**：接入视觉大模型（Qwen-VL），支持作业拍照、教材截图、
   公式回退图片（如维基百科 `img.mwe-math-fallback`）的公式识别，
   覆盖「纸面 → 听觉」的最后一块场景；
2. **WPS 小程序版**：面向文档编辑场景开发 WPS 小程序，让公式无障碍能力进入
   教师出题、学生写作业的文档工作流，探索与特教学校的协作分发；
3. **安卓手机端**：移动端是视障用户的第一上网设备，规划安卓端形态
   （读屏兼容的浏览器扩展替代方案），覆盖手机做题、听网课场景；
4. **符号读法用户自定义**：在分式读法枚举扩展位基础上，开放用户自定义朗读模板
   （斜线式等），把「个人偏好」升级为「个人配置」；
5. **符号范围扩展**：规则引擎向物理、化学、编程符号持续扩展，欢迎社区共建映射表；
6. **正式分发渠道**：Edge/Chrome 扩展商店上架（含可选权限说明与正式鉴权方案）、开源仓库运营。

## 七、社会价值与可持续性

- **直接受益人**：使用读屏软件的中小学生、大学生及其家长——
  理科学习从「需要专人陪读念题」变成「自己随时可学」；
- **可扩展性**：插件形态不挑网站，任何有公式的网页都能用；
  后续 OCR / WPS 小程序 / 安卓端将进一步覆盖纸面、文档、移动场景；
- **可持续运营**：常用转译走本地规则零成本，AI 仅用于复杂内容与讲解，
  云端按量计费成本可控、停止服务即停费；
- **开源计划**：项目参与开源贡献奖评选，计划开源并欢迎特教学校、公益组织共建；
- **隐私承诺**：不收集账号、不收集浏览记录，历史仅存用户本机；隐私政策随交付包提供；
- **长期愿景**：从「公式无障碍」走向「理科学习无障碍」，
  让视障学生拥有和健全学生一样的理科学习入口。
