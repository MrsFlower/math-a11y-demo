# 插件前台信息架构与状态流（第五阶段）

> 依据《给Qoder的插件前台产品形态说明.md》与《给Qoder的产品决策背景说明.md》。
> 形态定案：**Chrome/Edge Manifest V3 + Side Panel（侧边面板）**。
> 选 Side Panel 而非 Popup 的唯一理由是无障碍：Popup 在焦点离开时自动关闭，
> 读屏用户 Tab 回原页面核对公式时面板会消失，「确认→分析→追问」链路被打断；
> Side Panel 常驻页面旁边，正是「伴随式理解层」的桌面形态。

## 一、五区结构（面板从上到下）

| 区 | 内容 | 始终可见？ |
|---|---|---|
| 1. 状态区 | `role="status" aria-live="polite"`，所有状态变化在此播报 | 是 |
| 2. 捕获与确认区 | 「提取本页公式」「使用选中内容」按钮；候选公式列表；可编辑确认框 + 确认/重新提取/只复制 三按钮；兜底粘贴框 | 是 |
| 3. 解释区 | 短讲解（公式名+置信度徽章 / 可靠性提醒黄框 / 一句话总结 / 用途 / 直觉 / 变量表）+ `<details>` 详细解释折叠区 + 「在完整页面查看」链接（跳 Web 深度查看） | 分析完成后 |
| 4. 追问区 | 问题输入框 + 发送按钮 + 回答区（aria-live） | 分析完成后 |
| 5. 历史区 | `<details>` 折叠，真表格（时间/公式/操作），载入/复制/清空，存 `chrome.storage.local` 20 条 | 是（折叠） |

## 二、第一屏四问（识别待确认状态的卡片内容）

| 问题 | 对应元素 |
|---|---|
| 我捕到了什么 | 可编辑确认框里的 LaTeX + 来源说明（「来自本页 MathJax 公式」「来自选中文本，已转换」等） |
| 识别准不准 | 置信度文字（高=页面自带 LaTeX，零识别误差；低=文本转换，请检查）+ 结构朗读预览一行 |
| 要不要我确认 | 状态区播报「请确认识别结果，可直接编辑修改」，焦点自动落到确认框 |
| 下一步是什么 | 三按钮：确认并分析（主）/ 重新提取 / 只复制识别结果 |

## 三、状态机（六状态，全部有播报文本）

```
空闲 ──触发──▶ 捕获中 ──成功──▶ 识别待确认 ──确认──▶ 分析中 ──成功──▶ 已完成
  ▲               │失败                │重新提取            │失败/取消
  │               ▼                    ▼                    ▼
  └──────────  失败可重试（提示含下一步建议，可一键回到捕获或改用粘贴）
```

| 状态 | 播报文本 | 可用操作 |
|---|---|---|
| 空闲 | 「在页面上选中公式，或点提取本页公式开始」 | 提取/选中/粘贴 |
| 捕获中 | 「正在提取本页公式…」 | 无 |
| 识别待确认 | 「找到 N 个公式，请选择」或「请确认识别结果」 | 编辑/确认/重提/只复制 |
| 分析中 | 「正在分析，通常需要 20 秒左右」 | 取消 |
| 已完成 | 「分析完成：<公式名>」，焦点落到短讲解标题 | 复制/追问/历史/再来一条 |
| 失败可重试 | 具体原因 + 下一步建议（「后端未启动，请先运行服务」「改用粘贴」等） | 重试/回捕获 |

## 四、触发与捕获（三种触发，四层捕获优先级）

触发（任务书第一优先级全做）：
1. **右键菜单**：选中文本 → 右键「用公式助手解释」→ 打开面板并送入选中内容。
2. **快捷键**：`Alt+M`（可在 chrome://extensions/shortcuts 改）→ 打开面板；有选中内容则直接送入。
3. **面板内按钮**：「提取本页公式」扫描当前页所有公式节点，多个则列候选。
4. 工具栏图标点击 = 打开/关闭面板（openPanelOnActionClick）。

捕获优先级（能拿到源码就绝不 OCR）：
1. **页面自带 LaTeX**（零误差，confidence=high）：MathJax v2 `script[type="math/tex"]`、MathJax v3 assistive MathML、KaTeX `annotation[encoding="application/x-tex"]`、维基百科公式图 `img alt`。
2. **原生/内嵌 MathML**：`<math>` 节点，直接交后端。
3. **选中的普通文本**：像 LaTeX（含 `\命令`/`^`/`_`）则直接进确认；否则走 `POST /api/normalize-input` 转换后进确认。
4. **兜底粘贴框**：面板内手动粘贴，等同方式 3。
- 截图 OCR 不在插件主链路（Web 端保留），本阶段不做。

## 五、交互细节定案

- 面板宽度跟随浏览器 Side Panel 默认（约 320~400px），单列布局，字号 1rem 起。
- 展示顺序恒定：状态 → 捕获确认 → 短讲解 → 详细折叠 → 追问 → 历史。先短后长，默认不铺满。
- 确认按钮紧跟确认框之后（Tab 一步可达）；「确认并分析」为唯一主色按钮。
- 追问默认针对整条公式（插件不做结构树逐节点追问，那是 Web 深度查看页的职责）。
- 复制入口：结果区 3 个（短讲解 / LaTeX / 全部文本）；历史行内「复制总结」。
- 「听 AI 讲解」按钮（百炼 TTS）：与复制按钮同行，播 speech_text + 一段话总结，再按即停；
  只在用户点击时出声，绝不自动播放，面向低视力/未装读屏用户与演示，读屏用户不点它完全无感。
- 历史入口：面板底部 details 折叠区，标题含条数。
- 全键盘可用；焦点管理三处：捕获成功→确认框、分析完成→短讲解标题、追问回答→aria-live 自动读。
- 与 Web 端桥接：「在完整页面查看」= 打开 `http://127.0.0.1:8321/?latex=<encoded>`（Web 端读 query 预填输入框）。

## 六、Web 端保留职责（边界定死）

| 职责 | 说明 |
|---|---|
| 理解引擎 | 全部 API 不动，插件只是新客户端 |
| 深度查看 | 结构树、逐节点追问、A/B 对比、MathML 全文 |
| 调试/回归 | api_test / quality / language / eval 脚本全在 Web 侧跑 |
| 兜底输入 | 图片 OCR、大段 LaTeX 编辑 |
| 演示台 | 录屏、评估样例展示 |

## 七、技术要点备忘

- `manifest.json`：MV3；permissions = sidePanel / contextMenus / storage / activeTab / scripting；host_permissions = `http://127.0.0.1:8321/*`；commands 定义 Alt+M。
- 后台 service worker 只做消息路由：右键/快捷键 → 存 `chrome.storage.session` → 面板加载时取 + 运行时监听。面板可能未开，先 `chrome.sidePanel.open()`（用户手势内合法）。
- content script 按需注入（`chrome.scripting.executeScript`），不常驻，避免影响页面读屏。
- 历史存 `chrome.storage.local`（key 沿用 `math_a11y_history_v1` schema），与 Web localStorage 相互独立。
- 后端加 CORS 中间件（本地服务，放行所有来源即可）；扩展页面本身有 host_permissions，CORS 属双保险。
- 不做：Firefox 适配（sidebar API 不同，未来小改可迁）、系统级抓取、完整编辑器、OCR 主链路。
