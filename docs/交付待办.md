## 七、百炼平台发布（调研结论，2026-08-07）

结论：**可用作演示渠道，不能替代我们的正式分发路线。**

- 百炼「智能体应用（Agent 1.0）」支持发布为：魔笔网页分享、钉钉机器人、微信公众号、
  可复用组件、音视频实时互动；Agent 2.0 仅支持 API 调用。

  且网页 UI 是百炼通用对话界面，没有我们的双模式/双风格/历史/复制/焦点管理。
- 我们的核心链路（本地规则转译 + 自研 UI）跑在百炼之外，发布上去的只能是
  「理解模式 LLM 讲解」的纯对话 demo。
